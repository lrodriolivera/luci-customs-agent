AI Architecture & GPU Strategy

Current AI Stack

  • AWS Bedrock with Claude models (Haiku 4.5 / Sonnet 4.6 / Opus 4.6)
  • Agentic AI pipeline: classification → validation → generation → submission
  • Redis-backed inference cache (70%+ hit rate)
  • Multi-model routing: fast model for classification, powerful for complex H1 declarations
  • 6,490+ lines of AI orchestration logic

AI Capabilities

  • TARIC code classification from free-text descriptions (multilingual)
  • Document OCR + extraction (invoices, packing lists, certificates)
  • Customs regulation Q&A assistant (CAU, TARIC, regimes)
  • Anomaly detection on declaration data

GPU Inference Roadmap

  • On-premise LLMs — Deploy customs-specialized models for EU data residency (GDPR Art. 44+)
  • GPU-accelerated inference — Real-time batch processing of 1000+ declarations/hour during peak customs windows
  • Fine-tuning — Domain-specific models trained on multilingual tariff nomenclature (21,946 codes × 7 languages)
  • Multi-model serving — Parallel pipelines for classification + extraction + Q&A
  • Optimized latency — Sub-second inference for time-critical customs submissions (AEAT has 4-second timeout)
