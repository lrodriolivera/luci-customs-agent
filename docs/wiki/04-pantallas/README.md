# 4. Pantallas de LUCI

[← Volver al índice general](../README.md)

> Esta sección describe **todas las pantallas** de LUCI agrupadas por su lugar en el sidebar. Para cada pantalla: qué hace, qué botones tiene, cómo se relaciona con otras.

---

## Estructura del sidebar

LUCI tiene 7 grupos en el sidebar. Cada uno cubre una página de esta wiki:

| # | Grupo del sidebar | Pantallas | Para quién |
|---|---|---|---|
| 1 | **Operaciones** | Dashboard, Expedientes, Circuitos, Requerimientos, Inspecciones, Comunicaciones, Plazos, Garantías | Tu zona principal — todos los días |
| 2 | **Declaraciones** | Lista, H1, H7, AES, ENS, NCTS, PUE | Para presentar formalmente algo a AEAT |
| 3 | **Cálculo y Normativa** | Calculadora, Preferencias, Motor reglas, IIEE, Contingentes, Normativa, Clasificación | Cuando necesitas saber cuánto se paga o qué reglas aplican |
| 4 | **Control aduanero** | Inspecciones, Plazos, Comunicaciones, Consultas ADDS | Cuando AEAT te pregunta o te exige algo |
| 5 | **Regímenes** | Especiales, Garantías, OEA, Tránsitos | Operaciones no estándar |
| 6 | **AEAT e Integraciones** | Certificados, Monitor, Aduanas NL, Integraciones | Configurar y vigilar la integración |
| 7 | **Administración** | Analytics y BI, ML Insights, Configuración, Admin Panel | Solo para administradores del tenant |
