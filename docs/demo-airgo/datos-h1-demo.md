## Notas para la demo

### Puntos clave a destacar:
1. **H1 #1** - Caso real del tester, demuestra que el formulario soporta todos los campos
2. **H1 #2** - Multiples partidas, contenedores, AIRGO como destinatario
3. **H1 #3** - Preferencia EBA (0% arancel), exportador registrado REX, textil Bangladesh
4. **H1 #4** - Productos estacionales (frutas), EUR.1 Marruecos, IVA 4% superreducido, certificado ecologico
5. **H1 #5** - Vehiculo Japon, JEFTA (0% arancel), tipo cambio JPY, RoRo

### Codigos casilla 44 mas usados:
- N740: Conocimiento de embarque / AWB
- N380: Factura comercial
- N271: Packing list
- N018: Certificado ATR (union aduanera Turquia)
- N002: Certificado conformidad frutas/hortalizas
- C100: Numero exportador registrado (REX)
- C119: Certificado conformidad vehiculo (EASA Form 1)
- C644: Certificado control productos ecologicos
- 1403: Prueba origen - Declaracion en factura
- N337: Documento precedente G4 deposito temporal
